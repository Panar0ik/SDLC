
# Калькулятор Жизни (LifeCalculator)

**Автор:** Арсений Жигаловский  
**Дисциплина:** Жизненный цикл разработки программного обеспечения  
**Язык программирования:** Java 17  
**Графический интерфейс:** Java Swing  
**Система сборки:** Maven

## Описание проекта

«Калькулятор Жизни» — настольное приложение с графическим интерфейсом, предназначенное для расчёта возраста пользователя и приблизительных статистических показателей на основе даты рождения.

Программа позволяет определить количество прожитых дней и часов, а также оценить количество часов сна, морганий, сердцебиений, объём переработанной крови, потребление воды и количество смеха.

## Основные возможности

- Ввод и проверка даты рождения.
- Расчёт возраста и времени, прошедшего с даты рождения.
- Вычисление приблизительных статистических показателей.
- Автоматическое обновление интерфейса при изменении данных.
- Сохранение даты рождения между запусками приложения.
- Обработка некорректного пользовательского ввода.

## Архитектура

Проект использует архитектурный подход MVC с активной моделью.

- **Model:** `LifeModel`, `LifeData`, `LifeStatistics`.
- **View:** `MainFrame`, `InputDialog`.
- **Controller:** `LifeController`.
- **Точка входа:** `Main`.

Для уведомления об изменениях модели используется `PropertyChangeSupport`, а для сохранения данных — `Preferences`.

## Сборка и запуск

Для сборки проекта необходимы JDK 17 или новее и Maven.

```bash
mvn clean package
java -jar target/life-calculator-1.0-SNAPSHOT.jar
```
